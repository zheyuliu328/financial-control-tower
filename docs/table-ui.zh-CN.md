# 表格对账

[打开网页版](https://table-check-zheyuliu.mystic-pear-2111.chatgpt.site)。无需安装或注册。没有现成文件时，点击右上角“试用示例”，会直接显示虚构数据的核对结果。

## 用自己的文件

1. 选两份 CSV 或 Excel（.xlsx）。先看前两行预览，确认选对了文件；Excel 有多个工作表时需要选一张。列名没有读对时，展开“调整表头行”，填写真正写着列名的行号。
2. 点击“下一步：确认对应列”。选择两边用于匹配同一条记录的编号列，以及要比较的数值列。有明确列名时会预填建议，请确认它们的实际含义。单列不足以标识记录时可增加组合编号；也可比较多组数值。
3. 确认数值单位后开始。两侧都有币种列时逐行检查；没有币种列时，需要自己声明共同单位。默认不忽略任何数值差异，有明确标准时再展开“允许小误差”。

结果默认显示需要处理的项目。使用筛选和搜索定位差异，也可以查看全部检查。差异按“右表 − 左表”计算，源文件行号可用于回到原表查找。

## 下载和隐私

- “下载差异表（CSV）”：包含全部字段检查，可用 Excel 打开。页面筛选不改变下载内容。
- “下载报告（HTML）”：浏览器中可离线查看的完整报告。
- “下载结果与原表（ZIP）”：报告、差异表、精确结果、比较规则、文件校验值，以及两份原始文件的完整副本。原文件中没有参与核对的列和工作表也会保留，分享 ZIP 前请自行检查。

网页版的文件处理在浏览器 Worker 内存中完成，没有上传文件的应用接口，也不需要 AI API。首次使用下载约 14 MB 的计算组件；首次加载和处理过程可取消。页面刷新或关闭后当前结果会清空；改变输入或规则后需重新核对才能下载。

每份文件最多 8 MiB，同次核对最多 20,000 个潜在字段检查，最多 200 列。CSV 须为 UTF-8、逗号分隔；不支持 .xls、宏工作簿或密码保护工作簿。大型 Excel 的速度取决于设备；2 分钟未完成会停止处理。

## 比较规则

编号按原始文本精确匹配，保留前导零、空格和大小写。不会把 Excel 数字显示格式推断为文字编号。重复编号会列为受阻，不自动配对或加总；选中的 Excel 公式也会受阻，不在网页里重新计算。

币种不同或无效时停止相减；工具不换算汇率。容差为以下两者的较大值：绝对容差、相对容差乘以左右数值绝对值的较大值。相对容差填比例，例如 `0.01` 表示 1%。一套单位与容差适用于本次所有数值字段。

“全部在容差内”仅描述本次选中数据和字段的比较结果，不证明文件来源、覆盖范围、业务定义或模型正确。列名建议不会代替你的业务判断。

## 本机版

安装 Python 3.9 以上版本后，在仓库中执行：

```bash
python -m pip install '.[excel]'
fct-ui
```

macOS 可双击 `start-ui.command`。本机版向本机回环服务传递文件，单文件上限为 25 MiB；安装后可断网使用。网页样式和比较规则与网页版一致，命令行仍可使用 `fct-compare`。
