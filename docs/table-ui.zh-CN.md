# 在浏览器比较两张表

FCT 2.2 提供本机图形入口。你可以选择自己的 CSV 或 Excel 文件，明确匹配列和容差，再查看逐字段差异与源行。计算使用同一个 `fct-compare` 引擎。

## 打开工具

macOS 用户在仓库中双击 `start-ui.command`。首次启动需要 Python 3.9+，并会联网安装工具与 Excel 依赖；此后相同版本可直接离线启动。安装放在仓库自己的 `.venv-ui`，不修改系统 Python。升级版本后，启动入口会更新这个独立环境。

也可以在任意平台安装后运行：

```bash
python -m pip install '.[excel]'
fct-ui
```

默认地址为 `http://127.0.0.1:8767/`。如果端口已被占用，可用 `fct-ui --port 8768`。界面不依赖在线字体、外部脚本或云服务；浏览器将所选文件发送给本机进程，进程绑定回环地址，不向外部服务上传。安装依赖与实际文件处理是分开的。

## 一次完整比较

1. **选择左右文件。** 支持 UTF-8、逗号分隔 CSV 和 `.xlsx`。Excel 有多个工作表时必须明确选择；表头不是第一行时修改表头行。预览会显示原始行号、列名和部分单元格。先确认文件、工作表、表头和行数。
2. **配对匹配键。** 左右列名可以不同。每一行配对代表同一个业务字段；可添加多行形成复合键。键按精确文本匹配，保留前导零、大小写、空格与标点。重复键不会自动去重、合并或随意配对。
3. **配对数值字段。** 可比较一个或多个字段。所有字段共用所选容差，因此必须适用同一单位和容差口径。不能把需要不同容差的金额与比例直接混在一轮中。
4. **说明币种或共同单位。** 可在两边选择币种列；币种文字不一致时阻断相减。没有币种列时，填写共同单位，这是使用者的声明。工具不会推断单位、进行外汇换算或认证该声明。
5. **填写容差并比较。** 默认零容差。绝对容差是金额/数值单位，比例容差填小数，例如 `0.01` 代表 1%。规则是 `|右 − 左| ≤ max(绝对容差, 比例容差 × max(|左|, |右|))`。
6. **查看差异与覆盖。** 汇总单位是“字段检查”，另列左右输入行数与保留行数。可按状态、来源或文字筛选。筛选只改变视图，不会改变完整比较结果或导出包。
7. **查看报告并下载完整证据包。** 报告会保留所有匹配、差异、重复、缺失及无效项目。更改文件或设置后，旧结果的入口失效，需要重新比较。

可以先载入内置虚构示例熟悉操作；载入不会自动运行比较。示例故意包含币种冲突、重复键、单边记录与金额差异。

## 保留和复核结果

本机进程仅临时保留最近三次结果，合计最多 128 MiB；每份结果最多保留一小时。超过容量或关闭进程后，旧链接失效。需要留存的结果请下载 ZIP。原文件不会被覆盖；处理所用的临时副本在计算结束后清理。

解压后的文件包括：

| 文件 | 用途 |
| --- | --- |
| `report.html` | 可直接离线打开的完整报告；同目录中保留下面的伴随文件 |
| `differences.csv` | 全部字段结果，包含无效、重复及单边记录 |
| `comparison.json` | 精确原文、源行、映射、政策和完整结果 |
| `request.json` | 运行时的文件选择、匹配列、容差与单位设置 |
| `sources/left.csv` 或 `.xlsx` | 左侧选中文件的原始字节副本 |
| `sources/right.csv` 或 `.xlsx` | 右侧选中文件的原始字节副本 |
| `manifest.json` | 所有其他成员的 SHA-256、实际运行代码指纹及结果摘要 |

`request.json` 中的路径相对于解压目录，原文件名另有记录，不含设备绝对路径。第二次比较可以在界面重新选择 `sources/` 中的两个文件，再按 `request.json` 中的工作表、表头行、列映射、币种和容差设置运行。JSON 保留未改动原文；CSV 对可能触发电子表格公式的文本加安全前缀。

证据包包含完整选中文件，包括未映射列和其他 Excel 工作表。请按原文件的共享范围保存或转交。哈希能检查字节是否变化，不能证明来源真实性、业务含义或授权。

## 常见情况

- **Excel 数字格式显示了前导零：** 匹配键必须实际存为文本；把数字格式 `0000` 当成文本会丢失含义，工具会阻断。
- **选中 Excel 公式：** 公式不会执行，也不把旧缓存当成已验证结果。请另行提供经过核对的固化值副本。未映射的公式列不参与比较。
- **文件预览报错：** 先检查工作表、表头行、重复/空白列名、CSV 编码和分隔符。结构错误会停止执行，不生成成功报告。
- **没有差异：** 只代表给定两份文件在已声明规则下，参与比较的字段一致。不能发现同时缺失于两侧的记录，也不代表会计审批或模型验证通过。
- **文件太大：** 每份最多 25 MiB，最多 100000 个数据行、200 列；左右行数之和乘数值字段数最多 20000。浏览器导出包展开内容还限制在 100 MiB。请缩小范围或分批处理，不要删除异常行来换取通过。
